# MkDocs Smzhbook Theme

smallzh.top网站使用的主题，基于[MkDocs](https://mkdocs.readthedocs.io/) 构建。


## 0x01.开发
先安装 [uv](https://docs.astral.sh/uv/) ，再执行以下命令

```shell
# 创建虚拟环境
uv venv .venv
# 安装 mkdocs
uv pip install mkdocs
# 启动
uv run mkdocs serve
```
